# قدم أمان | Qadam Aman

تطبيق عربي مبني باستخدام Flutter لالتقاط صورة للقدم أو اختيارها من المعرض، ثم إرسالها إلى خادم تحليل يصنّف الصورة مبدئياً باستخدام نموذج تعلم آلي. يعرض التطبيق النتيجة مع إرشاد عام للخطوة التالية.

> **تنبيه طبي:** النتيجة تقدير آلي أولي وليست تشخيصاً طبياً، ولا تغني عن مراجعة طبيب أو مختص صحي. اطلب الرعاية الطبية عند وجود أعراض أو استمرار القلق.

## مكونات المشروع

- `flutter_app/`: تطبيق Flutter بواجهة عربية، يدعم التقاط الصور أو اختيارها من المعرض، ومعاينة الصورة وعرض نتيجة التحليل.
- `flutter_app/app.py`: خادم API مبني باستخدام FastAPI يستقبل الصورة ويشغّل نموذج LightGBM.
- `flutter_app/best_lightgbm_model.pkl` و`flutter_app/label_encoder.pkl`: ملفات النموذج وترميز الفئات اللازمة للتحليل.

## المتطلبات

- Flutter وDart وفق الإصدارات المحددة في `flutter_app/pubspec.yaml`.
- Python 3 وخادم FastAPI ومكتبات معالجة الصور والتعلم الآلي الموضحة أدناه.
- Android Studio أو محاكي Android (اختياري، لتشغيل نسخة Android).

## تشغيل خادم التحليل

من مجلد المشروع:

```bash
cd flutter_app
python -m pip install fastapi uvicorn python-multipart joblib pillow numpy scikit-image scikit-learn lightgbm
python app.py
```

يعمل الخادم افتراضياً على المنفذ `8000`. للتحقق من جاهزيته، افتح `http://127.0.0.1:8000/health` أو وثائق API على `http://127.0.0.1:8000/docs`.

## تشغيل تطبيق Flutter

في نافذة طرفية أخرى:

```bash
cd flutter_app
flutter pub get
flutter run
```

قبل التشغيل، اضبط `baseUrl` في `flutter_app/lib/config/api_config.dart` ليتصل التطبيق بالخادم:

- محاكي Android: `http://10.0.2.2:8000`
- هاتف حقيقي: استخدم عنوان IP للحاسوب على الشبكة المحلية.

يتطلب الاتصال من الهاتف والخادم أن يكونا على الشبكة نفسها. استخدم اتصالاً آمناً HTTPS وإعدادات إنتاج مناسبة عند النشر.

## تدفق التحليل

1. يلتقط المستخدم صورة أو يختارها من المعرض.
2. يرسل التطبيق الصورة إلى نقطة `POST /predict` في الخادم.
3. يحضّر الخادم الصورة ويستخرج ميزاتها، ثم يعيد الفئة المتوقعة.
4. يعرض التطبيق النتيجة والتنبيه المناسبين. لا يعرض التطبيق نسب الثقة للمستخدم.

لا يحتفظ التطبيق أو الخادم بالصورة بعد اكتمال طلب التحليل وفق التنفيذ الحالي. ينبغي مراجعة الخصوصية والأمان وإعدادات الخادم قبل إتاحة الخدمة للعامة.
